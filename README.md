# Computation Through Dynamics

This repository is for writing simulations and analyzing neural population
activity to study computation through dynamics. This framework explains how
changes in a population's activity over time can perform a computation.

Vyas, Golub, Sussillo, and Shenoy (2020) review the framework in
[Computation Through Neural Population Dynamics](https://doi.org/10.1146/annurev-neuro-092619-094115).
This project is separate from
[Google's archived JAX tutorials](https://github.com/google-research/computation-thru-dynamics)
on the same framework.

## Status

The repository includes editor and tooling configuration. It doesn't yet include
a runnable simulation, an analysis notebook, or a Python package.

## Set Up the Editor

To use the included workspace settings, open the repository folder in VS Code
and install the [recommended extensions](.vscode/extensions.json). The workspace
uses Ruff to format Python and Oxfmt to format Markdown and TOML.
